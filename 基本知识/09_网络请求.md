# `Promise` 介绍

## 概述

`Promise` 对象是 JavaScript 中用于处理异步操作的核心机制。它代表了一个异步操作的最终状态和结果。

在传统的异步编程（如回调函数）中，代码的执行顺序难以预测，容易导致“回调地狱”。`Promise` 提供了一种更优雅、更线性的方式来处理异步流程，让异步代码的编写和阅读体验接近同步代码。

一个 `Promise` 对象在其生命周期中，有且仅有以下三种互斥的状态：

1. Pending（等待中）

   初始状态。异步操作正在进行，既没有成功也没有失败。

2. Fulfilled（已成功）

   异步操作成功完成。此时 Promise 会携带一个结果值（Value）。

3. Rejected（已失败）

   异步操作失败。此时 Promise 会携带一个失败的原因或错误对象（Reason）。

>**状态流转的不可逆性**
>
>状态只能从 `Pending` 变为 `Fulfilled`，或者从 `Pending` 变为 `Rejected`。一旦状态发生改变（即被决议 Resolved），就会永远保持该状态，不会再次改变。

## 执行流程

Promise 的执行与 JavaScript 的事件循环（Event Loop）紧密相关。

1. 同步执行 Executor

   当 `new Promise()` 被调用时，传入的 Executor 函数会**立即同步执行**。

2. 异步决议

   当 Executor 内部调用了 `resolve` 或 `reject` 后，Promise 的状态发生改变。

3. 微任务队列

   与 Promise 状态改变绑定的后续回调（如 `.then()`、`.catch()` 中的函数）**不会立即同步执行**。它们会被放入事件循环的**微任务队列（Microtask Queue）**中。

4. 执行回调

   在当前调用栈（同步代码）清空后，引擎会优先清空微任务队列，依次执行这些回调函数。这保证了 Promise 回调的执行时机始终在同步代码之后、下一次 UI 渲染之前。

## 实例化格式

```javascript
new Promise(function(resolve, reject) {
  // resolve：一个函数，用于将 Promise 的状态从“等待中”变为“已成功”，并传递成功的结果值
  // reject：一个函数，用于将 Promise 的状态从“等待中”变为“已失败”，并传递失败的原因或错误对象
});
```

## 构造函数参数详解

| 参数名称   | 参数类型         | 作用描述                                                     | 可选值或说明                                        |
| ---------- | ---------------- | ------------------------------------------------------------ | --------------------------------------------------- |
| `executor` | 函数（Function） | 这是一个必选的执行器函数，<br />它会在 `Promise` 构造函数内部被立即同步执行。<br />接收 `resolve` 和 `reject` 两个函数作为参数，<br />用于控制异步操作的最终状态。 | 必须是一个函数，<br />否则会抛出 `TypeError` 错误。 |

在 Promise 构造函数中，实例化时传入的回调函数（通常称为 Executor 执行器）接收到的这两个函数参数（`resolve` 和 `reject`），其核心作用确实就是**改变 Promise 对象的状态**以及**传递相应的结果或错误原因**。

1. `resolve(value)`

   当异步操作成功时调用。它的作用是将 Promise 的状态从“等待中（pending）”变为“已成功（fulfilled）”，并将异步操作的成功结果（`value`）传递出去，供后续的 `.then()` 方法使用。

2. `reject(reason)`

   当异步操作失败时调用。它的作用是将 Promise 的状态从“等待中（pending）”变为“已失败（rejected）”，并将失败的原因（`reason`，通常是 Error 对象）传递出去，供后续的 `.catch()` 方法捕获。

## 常用属性

`Promise` 对象本身没有太多直接暴露的实例属性，其内部状态（如 `state` 和 `result`）是被封装隐藏的。

| 属性名称      | 所属对象            | 作用描述                                                     |
| ------------- | ------------------- | ------------------------------------------------------------ |
| `length`      | `Promise`           | 构造函数的静态属性，值为 `1`，<br />表示 `Promise` 构造函数只接受一个参数（即 `executor` 函数）。 |
| `prototype`   | `Promise`           | 构造函数的静态属性，指向 `Promise` 的原型对象，<br />所有的实例方法（如 `then`、`catch`）都定义在此之上。 |
| `constructor` | `Promise.prototype` | 原型对象上的属性，指回 `Promise` 构造函数本身。              |

## 常用方法

`Promise` 的方法分为定义在原型上的**实例方法**和定义在构造函数上的**静态方法**。

### 实例方法

| 方法名称                        | 作用描述                                                     | 返回值                                                       |
| ------------------------------- | ------------------------------------------------------------ | ------------------------------------------------------------ |
| `then(onFulfilled, onRejected)` | 为 `Promise` 添加处理成功（`onFulfilled`）或失败（`onRejected`）的回调函数。 | 返回一个新的 `Promise` 对象，支持链式调用。                  |
| `catch(onRejected)`             | 专门用于捕获和处理 `Promise` 链中发生的错误（即状态变为“已失败”的情况）。<br />等价于 `.then(null, onRejected)`。 | 返回一个新的 `Promise` 对象。                                |
| `finally(onFinally)`            | 指定无论 `Promise` 最终是成功还是失败，都必须执行的清理或收尾逻辑。<br />该回调不接收任何参数。 | 返回一个新的 `Promise` 对象，保持原始 `Promise` 的决议状态。 |

### 静态方法

#### 总体介绍

> 这些方法都会返回一个 `Promise` 对象。

| 方法名称                       | 作用描述                                                     |
| ------------------------------ | ------------------------------------------------------------ |
| `Promise.resolve(value)`       | 快速创建一个状态为“已成功”的 `Promise` 对象。<br />如果传入的值本身是 `Promise`，则直接返回该 `Promise`。 |
| `Promise.reject(reason)`       | 快速创建一个状态为“已失败”的 `Promise` 对象，并将传入的原因作为失败信息。 |
| `Promise.all(iterable)`        | 并发执行多个异步任务。<br />只有当所有传入的 `Promise` 都成功时，才返回一个包含所有成功结果的数组；<br />只要有一个失败，就立即返回该失败原因。 |
| `Promise.race(iterable)`       | 竞速执行多个异步任务。<br />返回第一个完成（无论是成功还是失败）的 `Promise` 的结果。<br />常用于实现异步请求的超时控制。 |
| `Promise.allSettled(iterable)` | 等待所有传入的 `Promise` 执行完毕（无论成功或失败）。<br />返回一个对象数组，每个对象包含对应任务的最终状态（`status`）以及成功值（`value`）或失败原因（`reason`）。 |
| `Promise.any(iterable)`        | 只要传入的 `Promise` 中有任何一个成功，就立即返回该成功的结果。<br />只有当所有传入的 `Promise` 都失败时，才返回一个包含所有失败原因的 `AggregateError`。 |

#### 详细介绍

| 对比维度     | `Promise.all`                                            | `Promise.race`                                               | `Promise.allSettled`                                         | `Promise.any`                                                |
| ------------ | -------------------------------------------------------- | ------------------------------------------------------------ | ------------------------------------------------------------ | ------------------------------------------------------------ |
| 核心作用     | 等待所有任务全部成功。                                   | 返回第一个完成的任务结果。                                   | 等待所有任务全部结束（无论成败）。                           | 只要有一个任务成功即可。                                     |
| 触发成功条件 | 传入的所有 `Promise` 都变为“已成功”。                    | 传入的任意一个 `Promise` 变为“已成功”或“已失败”。            | 传入的所有 `Promise` 都已决议（全部变为“已成功”或“已失败”）。 | 传入的任意一个 `Promise` 变为“已成功”。                      |
| 触发失败条件 | 传入的任意一个 `Promise` 变为“已失败”。                  | 传入的任意一个 `Promise` 变为“已失败”（且它是第一个完成的）。 | 永远不会失败（除非传入空数组或非法参数）。                   | 传入的所有 `Promise` 都变为“已失败”。                        |
| 返回值格式   | 一个数组，包含所有成功的结果值（顺序与传入顺序一致）。   | 第一个完成的 `Promise` 的结果值或失败原因。                  | 一个对象数组，每个对象包含 `status`（状态）和 `value`（成功值）或 `reason`（失败原因）。 | 第一个成功的 `Promise` 的结果值。                            |
| 典型应用场景 | 多个独立接口并发请求，且后续逻辑依赖所有接口的返回数据。 | 实现异步请求的超时控制（将一个正常请求与一个定时器 `Promise` 进行竞速）。 | 需要并发执行多个任务，且必须收集每个任务的最终执行结果（不关心个别失败）。 | 多个备用资源请求（如 CDN 节点），只要有一个节点响应成功即可。 |

## 代码示例

```js
// 1. 模拟一个异步操作（例如网络请求）
function fetchUserData(userId) {
    return new Promise((resolve, reject) => {
        console.log('正在请求用户数据...');
        
        // 模拟网络延迟 1 秒
        setTimeout(() => {
            if (userId === 1) {
                // 2. 请求成功：调用 resolve，将状态变为“已成功”
                resolve({ id: 1, name: '张三', age: 25 });
            } else {
                // 3. 请求失败：调用 reject，将状态变为“已失败”
                reject(new Error('用户不存在'));
            }
        }, 1000);
    });
}

// 4. 使用 Promise 处理异步结果
console.log('开始获取数据...');

fetchUserData(1)
    .then((data) => {
        // 成功时的处理逻辑
        console.log('获取成功:', data);
    })
    .catch((error) => {
        // 失败时的处理逻辑
        console.error('获取失败:', error.message);
    });

console.log('继续执行其他代码...');
```

# `fecth` 函数

`fetch()` 是浏览器（以及现代 Node.js 环境）提供的一个全局函数，用于发起网络请求（如 HTTP 或 HTTPS 请求）。它是传统的 `XMLHttpRequest` 的现代替代方案，基于 Promise 构建，语法更简洁，逻辑更清晰。

## 介绍

它是一个用于访问和操纵 HTTP 管道（如请求和响应）的 JavaScript 接口。通过调用 `fetch()` 并传入资源地址（URL）和可选的配置对象，它会返回一个 `Promise`。当请求完成时，`Promise` 会兑现为一个 `Response` 对象，随后可以调用 `response.json()` 或 `response.text()` 等方法来读取响应体。

可用于：

- 从服务器或 API 获取数据（如 JSON、HTML、图片等）。
- 向服务器发送数据（如提交表单、上传文件）。
- 执行跨域请求（需配合 CORS 机制）。
- 在现代前端框架（如 React、Vue）中进行数据请求。

## 使用格式

```javascript
fetch(resource, init)
// resource：必需参数，定义要获取的资源。可以是一个 URL 字符串，也可以是一个 Request 对象。
// init：可选参数，一个配置对象，用于自定义请求的各项设置（如请求方法、请求头、请求体等）。
```

## 参数详解

| 参数名称   | 参数类型              | 作用描述                           | 可选值或说明                                                 |
| ---------- | --------------------- | ---------------------------------- | ------------------------------------------------------------ |
| `resource` | 字符串或 Request 对象 | 定义要获取的资源地址。             | 通常是一个 URL 字符串（如 `'https://api.example.com/data'`），<br />也可以是一个 `Request` 对象。 |
| `init`     | 对象（Object）        | 一个包含请求自定义设置的配置对象。 | 常用属性包括：<br />`method`（请求方法）、<br />`headers`（请求头）、<br />`body`（请求体）、<br />`mode`（请求模式）、<br />`credentials`（凭据设置）、<br />`cache`（缓存模式）、<br />`redirect`（重定向处理）、<br />`signal`（中止信号）等。 |

## 代码示例

以下是一个使用 `fetch()` 发起 GET 请求并处理响应的完整示例。

```javascript
// 发起一个 GET 请求
fetch('https://jsonplaceholder.typicode.com/posts/1')
  .then(response => { // 请求成功，会变为 Response 对象
    // 检查请求是否成功（状态码在 200-299 之间）
    if (!response.ok) {
      throw new Error(`HTTP error! status: ${response.status}`);
    }
    // 将响应体解析为 JSON 格式
    return response.json();
  })
  .then(data => {
    // 处理获取到的数据
    console.log('获取到的数据:', data);
  })
  .catch(error => {
    // 捕获网络错误或手动抛出的错误
    console.error('请求失败:', error);
  });
```

## 注意点

`fetch()` 返回的 Promise 只有在发生网络故障或请求被阻止时才会被拒绝（reject）。

如果服务器返回了 HTTP 错误状态码（如 `404` 或 `500`），Promise 依然会处于成功（resolve）状态。因此，必须手动检查 `response.ok` 或 `response.status` 来判断业务请求是否真正成功。

# `then` 方法

## 介绍

`.then()` 方法是 JavaScript 中 `Promise` 对象的核心实例方法，用于为 `Promise` 实例注册状态改变时的回调函数。当 `Promise` 的状态从“等待中”变为“已成功”或“已失败”时，它会异步执行对应的处理逻辑。

它通常用在异步操作（如网络请求、文件读取）之后，用来处理返回的数据或捕获错误，并且它总是返回一个新的 `Promise` 对象，从而支持链式调用，让异步代码的编写更加线性和清晰。

## 使用格式

```javascript
promise.then(onFulfilled, onRejected)
// onFulfilled：可选参数，一个函数。当 Promise 的状态变为“已成功（fulfilled）”时被调用，接收 Promise 的成功结果值作为参数。
// onRejected：可选参数，一个函数。当 Promise 的状态变为“已失败（rejected）”时被调用，接收 Promise 的失败原因作为参数。
```

## 参数详解

| 参数名称      | 作用描述                            | 可选值或说明                                                 |
| ------------- | ----------------------------------- | ------------------------------------------------------------ |
| `onFulfilled` | 处理 `Promise` 成功状态的回调函数。 | 如果该参数不是函数，<br />则内部会被替换为一个恒等函数（`(x) => x`），简单地将成功值向前传递。 |
| `onRejected`  | 处理 `Promise` 失败状态的回调函数。 | 如果该参数不是函数，<br />则内部会被替换为一个抛出器函数（`(x) => { throw x; }`），它会抛出收到的失败原因。 |

这两个回调参数的参数就是 Promise 对象成功或失败的结果。

## 简单代码示例

以下是一个展示 `.then()` 方法基本用法及链式调用的示例。

```javascript
// 创建一个已成功的 Promise
const myPromise = Promise.resolve('初始数据');

myPromise
  .then(
    (value) => {
      // 第一个 then：处理成功状态
      console.log('第一步处理:', value); // 输出: 第一步处理: 初始数据
      return value + ' -> 处理后的数据'; // 返回一个新值，传递给下一个 then
    },
    (reason) => {
      // 处理失败状态（本例不会触发）
      console.error('发生错误:', reason);
    }
  )
  .then((newValue) => {
    // 第二个 then：接收上一步返回的值
    console.log('第二步处理:', newValue); // 输出: 第二步处理: 初始数据 -> 处理后的数据
  });
```

# `Response` 对象

## 介绍

`Response` 对象是 JavaScript Fetch API 的核心组成部分，代表了一次网络请求（如 `fetch()`）返回的完整响应。它封装了服务器返回的 HTTP 状态码、响应头以及响应体（真正的业务数据）。

通常在发起网络请求并获取到 Promise 的兑现结果后使用，通过调用其提供的异步方法（如 `.json()`、`.text()`）来提取和处理不同格式的数据，或者通过检查其属性（如 `.ok`、`.status`）来判断请求是否成功。

## 实例化格式

```javascript
new Response(body, init)
// body：可选参数，定义响应体的内容。可以是 null、字符串、Blob、ArrayBuffer、FormData、URLSearchParams 或 ReadableStream 对象。
// init：可选参数，一个配置对象，用于自定义响应的状态码、状态文本和头部信息。
```

## 参数详解

| 参数名称 | 作用描述                               | 可选值或说明                                                 |
| -------- | -------------------------------------- | ------------------------------------------------------------ |
| `body`   | 定义响应体的具体内容。                 | `null`（默认值）、<br />`字符串`、<br />`Blob`、<br />`ArrayBuffer`、<br />`TypedArray`、<br />`DataView`、<br />`FormData`、<br />`URLSearchParams`、<br />`ReadableStream`。 |
| `init`   | 一个包含响应自定义设置的配置**对象**。 | 常用属性包括：<br />`status`（HTTP 状态码）、<br />`statusText`（状态文本）、<br />`headers`（响应头信息）。 |

## 常用属性

| 属性名称     | 作用描述                                                     |
| ------------ | ------------------------------------------------------------ |
| `status`     | 返回 HTTP 状态码（数值类型），例如 `200`、`404`、`500`。     |
| `ok`         | 返回一个布尔值。当 HTTP 状态码在 200 到 299 之间时为 `true`，表示请求成功；否则为 `false`。 |
| `statusText` | 返回与状态码对应的状态文本描述（字符串类型），例如 `"OK"` 对应 `200`，`"Not Found"` 对应 `404`。 |
| `headers`    | 返回一个 `Headers` 对象，包含了响应的所有头部信息。          |
| `url`        | 返回该响应的最终 URL 字符串。如果请求过程中发生了重定向，该属性返回的是重定向后的最终地址。 |
| `redirected` | 返回一个布尔值，表示该响应是否是由一个或多个重定向产生的。   |
| `type`       | 返回响应的类型（字符串类型），例如 `basic`（同源请求）、`cors`（跨域请求）或 `error`（网络错误）。 |
| `bodyUsed`   | 返回一个布尔值，标示响应体（Body）是否已经被读取过。         |
| `body`       | 返回一个 `ReadableStream` 对象，代表响应体的内容流。         |

## 常用方法

| 方法名称              | 作用描述                                                     |
| --------------------- | ------------------------------------------------------------ |
| `json()`              | 读取响应体，并将其解析为 JSON 对象后返回一个 Promise。       |
| `text()`              | 读取响应体，并将其解析为纯文本字符串后返回一个 Promise。     |
| `blob()`              | 读取响应体，并将其解析为二进制大对象（Blob）后返回一个 Promise。常用于处理图片或文件下载。 |
| `arrayBuffer()`       | 读取响应体，并将其解析为二进制数组缓冲区（ArrayBuffer）后返回一个 Promise。适用于底层的二进制数据处理。 |
| `formData()`          | 读取响应体，并将其解析为 `FormData` 表单对象后返回一个 Promise。 |
| `clone()`             | 创建一个当前 `Response` 对象的完整副本。由于响应体只能读取一次，当需要在不同的地方以不同的格式解析同一份响应数据时，必须先调用此方法克隆对象。 |
| `Response.error()`    | 静态方法，返回一个绑定了网络错误的新的 `Response` 对象。     |
| `Response.redirect()` | 静态方法，用另一个 URL 创建一个新的重定向 `Response` 对象。  |
