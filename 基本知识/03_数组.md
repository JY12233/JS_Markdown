# 基础知识

`Array`（数组）是 JavaScript 中用于在单个变量中存储多个有序值的内置对象。它通过方括号 `[]` 或 `new Array()` 进行实例化，支持动态调整长度，并能在同一个数组中存放任意类型的数据。当需要管理一组相关的数据集合、进行批量数据处理（如遍历、筛选、转换）或实现队列与栈等数据结构时，数组是最核心且最常用的工具。

## 实例化格式

```javascript
const arr = new Array(element0, element1, /* … ,*/ elementN);
// new：触发构造函数机制的关键字，启动数组创建流程。
// element0, element1...：用于初始化数组的元素列表。如果仅传入一个数字参数，则该数字代表数组的长度（创建空槽数组），而非数组的元素。
// arr：最终创建并返回的数组实例。
```

## 参数详解

| 参数名称 | 作用描述             | 可选值或数据类型                                             |
| -------- | -------------------- | ------------------------------------------------------------ |
| elementN | 指定数组的初始元素。 | 任意数据类型（字符串、数字、对象、函数等）。<br />若仅传入一个正整数，则创建指定长度的空数组。 |

## 常用静态方法

| 方法名称                            | 作用描述                                                     |
| ----------------------------------- | ------------------------------------------------------------ |
| `Array.isArray(value)`              | 检测传递的值是否是一个数组，返回布尔值。                     |
| `Array.from(arrayLike, mapFn?)`     | 从类数组对象（如 `NodeList`）或可迭代对象（如 `String`）创建一个新的数组实例。 |
| `Array.of(element0, element1, ...)` | 通过可变数量的参数创建一个新的数组实例，无论参数是单个数字还是多个值，都直接作为数组元素。 |

## 常用实例属性与方法

| 属性/方法名称                           | 作用描述                                                     |
| --------------------------------------- | ------------------------------------------------------------ |
| `length`                                | 设置或返回数组中元素的数量。                                 |
| `push(...elements)`                     | 将一个或多个元素添加到数组的末尾，并返回新的长度。           |

# 判断所有元素是否符合条件

`some` 和 `every` 是 JavaScript 数组中两个非常实用的方法，它们都用于判断数组中的元素是否符合某个条件，但逻辑正好相反。

## `some()`

`some()` 方法用于检测数组中**是否有至少一个**元素通过了提供的函数测试。只要找到一个符合条件的元素，它就会立即返回 `true`；如果所有元素都不符合条件，则返回 `false`。可以把它理解为逻辑“或”（OR）操作。

### 使用格式

```javascript
array.some(
  callbackFn,      // 一个用于测试每个元素的函数。
  thisArg          // 执行 callbackFn 时用作 this 的值
);
```

### 参数详解

| 参数         | 作用                                                         | 可选值及说明                                                 |
| ------------ | ------------------------------------------------------------ | ------------------------------------------------------------ |
| `callbackFn` | 一个用来测试每个元素的函数。                                 | 该函数应返回一个可以被转换为布尔值的值。<br />如果返回 `true`（或真值），<br />`some` 方法会立即返回 `true` 并停止遍历。 |
| `thisArg`    | 可选参数，用于在执行 `callbackFn` 时，指定函数内部 `this` 的值。 | 任意类型的值。<br />如果省略，在非严格模式下 `this` 指向全局对象<br />（浏览器中是 `window`），在严格模式下为 `undefined`。 |

### 代码示例

```javascript
const numbers = [1, 3, 5, 8, 9];

// 检查数组中是否有偶数
const hasEven = numbers.some((num) => {
  return num % 2 === 0;
});

console.log(hasEven); // 输出: true (因为数字 8 是偶数)
```

## `every()` 方法

`every()` 方法用于检测数组中**所有**元素是否都通过了提供的函数测试。只有当数组中的每一个元素都符合条件时，它才会返回 `true`；只要有一个元素不符合，就立即返回 `false`。可以把它理解为逻辑“与”（AND）操作。

### 使用格式

```javascript
array.every(
  callbackFn,      // 必填：一个用于测试每个元素的函数。它接收三个参数：element（当前元素）、index（当前索引）、array（原数组）
  thisArg          // 可选：执行 callbackFn 时用作 this 的值
);
```

### 参数详解

| 参数         | 作用                                                         | 可选值及说明                                                 |
| ------------ | ------------------------------------------------------------ | ------------------------------------------------------------ |
| `callbackFn` | 一个用来测试每个元素的函数。                                 | 该函数应返回一个可以被转换为布尔值的值。<br />如果返回 `false`（或假值），`every` 方法会立即返回 `false` 并停止遍历。 |
| `thisArg`    | 可选参数，用于在执行 `callbackFn` 时，指定函数内部 `this` 的值。 | 任意类型的值。<br />如果省略，在非严格模式下 `this` 指向全局对象<br />（浏览器中是 `window`），在严格模式下为 `undefined`。 |

### 代码示例

```javascript
const numbers = [2, 4, 6, 8];

// 检查数组中是否所有数字都大于 0
const allPositive = numbers.every((num) => {
  return num > 0;
});

console.log(allPositive); // 输出: true (因为所有数字都大于 0)
```

# 过滤

`filter` 是 JavaScript 数组的一个高阶方法，用于根据指定的条件从原数组中筛选出符合条件的元素，并返回一个包含这些元素的新数组。它不会修改原数组，而是生成一个全新的数组。当需要从大量数据中提取出满足特定规则（如过滤掉无效数据、查找特定状态的用户等）的子集时，`filter` 是最佳选择。

## 使用格式

```javascript
const newArray = array.filter(callback(element, index, array), thisArg);
// callback：用于测试每个元素的回调函数，返回 true 表示保留该元素，返回 false 表示过滤掉。
// element：当前正在处理的数组元素。
// index：当前元素的索引（可选参数）。
// array：调用 filter 方法的数组本身（可选参数）。
// thisArg：执行回调时用作 this 的对象（可选参数）。
```

## 参数详解

| 参数名称   | 作用描述                                           | 可选值或数据类型               |
| ---------- | -------------------------------------------------- | ------------------------------ |
| `callback` | 测试每个元素的函数，返回布尔值决定元素是否被保留。 | 必须是一个函数。               |
| `element`  | 当前正在遍历的数组元素。                           | 任意数据类型（由原数组决定）。 |
| `index`    | 当前元素的索引位置。                               | 数字（Number），可选参数。     |
| `array`    | 调用 filter 的原数组引用。                         | 数组（Array），可选参数。      |
| `thisArg`  | 指定回调函数执行时的 this 指向。                   | 任意对象，可选参数。           |

## 代码示例

```javascript
const numbers = [1, 2, 3, 4, 5, 6];
// 筛选出所有大于 3 的偶数
const result = numbers.filter((num) => num > 3 && num % 2 === 0);
console.log(result); // 输出: [4, 6]
```

# 累积

`reduce` 是 JavaScript 数组的一个高阶方法，用于将数组中的所有元素按顺序（从左到右）通过一个回调函数进行累积计算，最终归约为一个单一的值。当需要对数组进行求和、求积、统计元素出现次数、数组去重、多维数组扁平化或将数组转换为对象等复杂的数据聚合操作时，`reduce` 是最强大且最灵活的工具。

## 使用格式

```javascript
const result = array.reduce(callback(accumulator, currentValue, currentIndex, array), initialValue);
// array：调用 reduce 方法的原数组。
// callback：用于处理数组中每个元素的回调函数（Reducer 函数）。
// accumulator：累加器，保存上一次回调函数的返回值，或初始值。
// currentValue：当前正在处理的数组元素。
// currentIndex：当前元素的索引（可选参数）。
// array：调用 reduce 的原数组本身（可选参数）。
// initialValue：作为第一次调用回调函数时累加器的初始值（可选参数）。
// result：最终累积计算后的单一返回值。
```

## 参数详解

| 参数名称       | 作用描述                                                     | 可选值或数据类型                           |
| -------------- | ------------------------------------------------------------ | ------------------------------------------ |
| `callback`     | 对数组中的每个元素执行的函数，<br />其返回值会作为下一次调用的累加器。 | 必须是一个函数。                           |
| `accumulator`  | 累积上一次回调的结果。<br />若提供了初始值，则首次为初始值；否则为数组第一个元素。 | 任意数据类型（由初始值或回调返回值决定）。 |
| `currentValue` | 当前正在被处理的数组元素。                                   | 任意数据类型（由原数组决定）。             |
| `currentIndex` | 当前元素的索引。若提供了初始值，则从 0 开始；<br />否则从 1 开始。 | 数字（Number），可选参数。                 |
| `array`        | 调用 reduce 的原数组引用。                                   | 数组（Array），可选参数。                  |
| `initialValue` | 第一次调用回调时累加器的初始值。<br />强烈建议提供此参数以避免空数组报错。 | 任意数据类型，可选参数。                   |

## 代码示例

```javascript
const numbers = [1, 2, 3, 4];

// 1. 基础用法：数组求和
// 箭头函数只有一行可以省略 return
const sum = numbers.reduce((acc, cur) => acc + cur, 0);
console.log(sum); // 输出: 10

// 2. 进阶用法：统计数组中每个元素出现的次数
const fruits = ['apple', 'banana', 'apple', 'orange', 'banana', 'apple'];
const countFruits = fruits.reduce((acc, cur) => {
  acc[cur] = (acc[cur] || 0) + 1; // 如果属性存在则加1，否则初始化为1。
  return acc; // 必须返回累加器对象，供下一次迭代使用。
}, {}); // 初始值为空对象。

console.log(countFruits); // 输出: { apple: 3, banana: 2, orange: 1 }
```

# 真数组转换

使用 `Array.from` 或者扩展运算符 `...`。

## 转换机制

`Array.from()` 和扩展运算符（`...`）虽然都能将伪数组转换为真正的数组，但它们的底层转换机制存在显著差异。

- 扩展运算符（`...`）

  底层依赖于 JavaScript 的**迭代器协议（Iterator Protocol）**。它只能转换那些实现了 `[Symbol.iterator]` 方法的可迭代对象（如 `NodeList`、`arguments`、`String`）。如果伪数组没有实现迭代器，扩展运算符会直接报错。

- `Array.from()`

  底层依赖于**类数组对象（Array-like）的协议**。它只要求目标对象拥有 `length` 属性和数字索引即可进行转换，**不强制要求**实现迭代器协议。因此，它的兼容性更强，能处理更多“不标准”的伪数组。

## 映射与转换能力

- 扩展运算符（`...`）

  仅负责“展开”和“复制”，不具备在转换过程中对元素进行处理的能力。如果需要转换后立刻对每个元素进行加工，必须再链式调用 `.map()` 方法。

- `Array.from()`

  原生支持**映射函数（Map Function）**作为第二个参数。它可以在将伪数组转换为真数组的同一过程中，直接对每个元素执行转换逻辑，相当于 `Array.from(obj).map(fn)` 的语法糖，性能更优且代码更简洁。

## 对比总结

| 对比维度         | 扩展运算符（...）                                           | Array.from()                                         |
| ---------------- | ----------------------------------------------------------- | ---------------------------------------------------- |
| **底层依赖**     | 迭代器协议（`[Symbol.iterator]`）                           | 类数组协议（`length` + 数字索引）                    |
| **转换能力**     | 仅支持可迭代对象，遇到无迭代器的伪数组会报错                | 支持所有类数组对象，兼容性更强                       |
| **元素映射**     | 不支持，需额外链式调用 `.map()`                             | 支持，第二个参数可直接传入映射函数                   |
| **this 指向**    | 无法在转换过程中指定 `this`                                 | 第三个参数可指定映射函数执行时的 `this` 值           |
| **典型适用场景** | 转换 `NodeList`、`arguments`、`Set`、`Map` 等标准可迭代对象 | 转换自定义伪数组、对象字面量（配合映射函数生成序列） |

## 代码示例

```javascript
// 1. 扩展运算符：仅能转换可迭代对象，无法在转换时映射
const nodeList = document.querySelectorAll('div');
const arr1 = [...nodeList]; // 成功转换
// const arr2 = [...{0: 'a', length: 1}]; // 报错：该对象不可迭代

// 2. Array.from()：支持转换无迭代器的伪数组，且支持映射
const objLike = { 0: 'a', 1: 'b', length: 2 };
const arr3 = Array.from(objLike); // 成功转换: ['a', 'b']

// 3. Array.from() 的映射能力：转换时直接处理元素
const numbers = { 0: 1, 1: 2, 2: 3, length: 3 };
const doubled = Array.from(numbers, (value) => value * 2);
console.log(doubled); // 输出: [2, 4, 6]
```

## 实践建议

- 当处理浏览器原生 API 返回的对象（如 `NodeList`、`arguments`）时，两者皆可，**扩展运算符（...）** 语法更简洁。
- 当处理自定义的、可能没有迭代器的伪数组，或者需要在转换的同时对元素进行加工时，必须使用 `Array.from()`。
