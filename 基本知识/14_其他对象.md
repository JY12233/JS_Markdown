# 迅速获取表单值

`FormData` 对象是 JavaScript 中用于迅速获取和处理 HTML 表单数据的内置接口，它能够将表单内所有带有 `name` 属性的元素值自动收集并组织为键值对集合。在使用时，只需通过 `new FormData(formElement)` 传入表单元素即可初始化，随后便可调用其提供的方法来读取、遍历或追加数据。它主要适用于需要批量获取表单数据、进行前端数据验证、通过 AJAX（如 `fetch` 或 `axios`）异步提交表单，以及处理包含文件上传的复杂表单等场景。

## 使用格式

```javascript
// 1. 初始化 FormData 对象
const formData = new FormData(
  formElement // 表单元素：传入一个 HTML <form> 元素，FormData 会自动收集该表单内所有带 name 属性的控件值
);

// 2. 获取指定键名的值
const value = formData.get(
  name // 键名：字符串类型，对应表单元素的 name 属性值，用于获取该字段的第一个值
);

// 3. 获取指定键名的所有值（适用于复选框等多值元素）
const values = formData.getAll(
  name // 键名：字符串类型，对应表单元素的 name 属性值，返回一个包含该字段所有值的数组
);

// 4. 追加新的键值对
formData.append(
  name, // 键名：字符串类型，指定要追加的字段名称
  value // 键值：可以是字符串或 File/Blob 对象，指定要追加的字段值
);

// 5. 设置或覆盖指定键名的值
formData.set(
  name, // 键名：字符串类型，指定要设置的字段名称
  value // 键值：字符串或 File/Blob 对象，若键名已存在则覆盖原值，不存在则新增
);

// 6. 删除指定键名的键值对
formData.delete(
  name // 键名：字符串类型，指定要删除的字段名称
);

// 7. 检查是否存在指定键名
const hasKey = formData.has(
  name // 键名：字符串类型，检查 FormData 中是否包含该字段，返回布尔值
);

// 8. 获取所有键值对的迭代器
const entries = formData.entries(); // 返回一个迭代器对象，可用于 for...of 循环遍历所有键值对
```

## 方法与属性

| 方法/属性名称         | 作用描述                         | 可选值或数据类型                                             |
| --------------------- | -------------------------------- | ------------------------------------------------------------ |
| `get(name)`           | 获取指定键名的第一个值           | 返回 `string` 或 `File` 对象；若键名不存在则返回 `null`      |
| `getAll(name)`        | 获取指定键名的所有值             | 返回 `string[]` 或 `File[]` 数组；若键名不存在则返回空数组   |
| `append(name, value)` | 向 FormData 中追加一个新的键值对 | `value` 可选值为 `string`、`Blob`、`File`；若键名已存在，则保留原值并追加新值 |
| `set(name, value)`    | 设置指定键名的值                 | `value` 可选值为 `string`、`Blob`、`File`；若键名已存在，则覆盖原值 |
| `delete(name)`        | 删除指定键名的键值对             | 无返回值                                                     |
| `has(name)`           | 检查是否存在指定键名             | 返回 `true` 或 `false`                                       |
| `entries()`           | 获取所有键值对的迭代器           | 返回一个迭代器对象，常配合 `for...of` 循环使用               |
| `keys()`              | 获取所有键名的迭代器             | 返回一个迭代器对象，仅包含键名                               |
| `values()`            | 获取所有键值的迭代器             | 返回一个迭代器对象，仅包含键值                               |

## 简单代码示例

以下示例展示了如何在表单提交时，使用 `FormData` 迅速获取所有表单值并通过 `fetch` 发送到服务器：

```javascript
// 获取表单元素并监听提交事件
document.querySelector('form').addEventListener('submit', function(event) {
  event.preventDefault(); // 阻止表单默认的页面刷新行为

  // 迅速获取整个表单的数据
  const formData = new FormData(this);

  // 遍历并打印所有表单字段的值
  for (const [key, value] of formData.entries()) {
    console.log(`${key}: ${value}`);
  }

  // 将数据发送到服务器
  fetch('/api/submit', {
    method: 'POST',
    body: formData // 直接将 FormData 对象作为请求体，浏览器会自动设置正确的 Content-Type
  });
});
```

# AbortController  对象

`AbortController` 是浏览器原生提供的一个 Web API 对象，主要用于在需要时中止一个或多个异步操作（最常见的是取消 `fetch` 网络请求）。

在使用时，首先通过 `new AbortController()` 创建一个控制器实例，然后将其关联的 `signal` 属性传递给需要被控制的异步操作（如 `fetch` 请求或事件监听），最后在需要取消操作时调用该实例的 `abort()` 方法。

它主要适用于用户切换页面、搜索框防抖取消旧请求、设置请求超时，以及在组件卸载时自动清理事件监听器等场景。

## 实例化格式

```javascript
const controller = new AbortController(); // 创建一个新的 AbortController 控制器实例，无需传入任何参数
```

## 常用属性

| 属性名称 | 作用描述                                                     | 可选值或数据类型               |
| -------- | ------------------------------------------------------------ | ------------------------------ |
| `signal` | 返回一个 `AbortSignal` 对象实例，<br />该对象可被传递给各种异步操作（如 `fetch`、`addEventListener`），<br />用于监听中止状态 | `AbortSignal` 对象（只读属性） |

## 常用方法

| 方法名称  | 作用描述                                                     | 参数说明                                                     |
| --------- | ------------------------------------------------------------ | ------------------------------------------------------------ |
| `abort()` | 触发关联的 `signal` 的中止事件，<br />使所有监听该信号的异步操作立即停止 | 接受一个可选参数 `reason`（任意类型），用于指定中止的原因。<br />若未提供，默认原因为 `DOMException`（名称为 `AbortError`） |

**`controller.abort()` 是不可逆的**。

一旦调用了 `abort()`，该 `AbortSignal` 就会永久进入“已中止”状态。如果随后尝试用同一个 `signal` 去绑定新的事件时，浏览器会检测到信号已经处于中止状态，从而**直接丢弃该监听器**，导致事件永远无法触发。

## 与其他对象的联动

由于 `AbortController` 的核心是通过 `signal` 属性与 `AbortSignal` 配合使用，以下 `AbortSignal` 的静态方法在实际开发中常与 `AbortController` 结合使用。

| 静态方法名称            | 作用描述                                                     | 参数说明                                                     |
| ----------------------- | ------------------------------------------------------------ | ------------------------------------------------------------ |
| `AbortSignal.timeout()` | 返回一个在指定时间后自动中止的 `AbortSignal` 实例，<br />常用于设置请求超时 | 接受一个 `number` 类型的参数，<br />表示超时时间（单位：毫秒） |
| `AbortSignal.any()`     | 返回一个新的 `AbortSignal`，<br />当传入的任意一个信号被中止时，该信号也会被中止 | 接受一个 `AbortSignal` 数组，<br />用于合并多个中止信号      |
| `AbortSignal.abort()`   | 直接返回一个已经处于中止状态的 `AbortSignal` 实例，<br />常用于条件不满足时立即阻止操作 | 接受一个可选参数 `reason`，<br />用于指定中止原因            |

## 代码示例

### fetch 请求超时取消

以下示例展示了如何结合 `AbortController` 与 `AbortSignal.timeout()`，实现一个带有超时自动取消功能的网络请求。

```javascript
async function fetchWithTimeout(url, timeoutMs) {
  // 1. 创建 AbortController 实例
  const controller = new AbortController();

  // 2. 创建超时信号（若超时，信号会自动触发中止）
  const timeoutSignal = AbortSignal.timeout(timeoutMs);

  // 3. 合并两个信号：手动取消或超时，任一触发即中止请求
  const signal = AbortSignal.any([controller.signal, timeoutSignal]);

  try {
    // 4. 发起 fetch 请求，并传入合并后的 signal
    const response = await fetch(url, { signal });
    const data = await response.json();
    console.log('请求成功:', data);
  } catch (error) {
    // 5. 捕获中止错误
    if (error.name === 'AbortError') {
      console.log('请求已被中止（可能是超时或手动取消）');
    } else {
      console.error('请求失败:', error);
    }
  }
}

// 使用示例：请求数据，若 3000 毫秒内未响应则自动取消
fetchWithTimeout('https://api.example.com/data', 3000);
```

### 事件监听批量清理

以下示例展示了如何利用 `AbortController` 在组件卸载或特定条件触发时，一次性清理绑定的多个事件监听器。

```javascript
// 1. 创建控制器实例
const controller = new AbortController();

// 2. 获取目标元素
const button = document.querySelector('#myButton');

// 3. 绑定多个事件，并统一传入 signal
button.addEventListener('click', () => {
  console.log('按钮被点击');
}, { signal: controller.signal });

button.addEventListener('mouseenter', () => {
  console.log('鼠标移入');
}, { signal: controller.signal });

button.addEventListener('mouseleave', () => {
  console.log('鼠标移出');
}, { signal: controller.signal });

// 4. 当需要清理所有事件时（例如页面跳转、组件销毁），只需调用一次 abort
controller.abort(); 
```
