# 介绍

在 JavaScript 中，`window` 对象是浏览器对象模型（BOM）的核心，它代表了当前浏览器窗口或标签页。与常规类不同，它不需要手动实例化，而是作为全局对象直接提供。

## 获取格式

`window` 对象是全局可用的，可以通过以下两种方式获取：

```javascript
window;   // 标准写法：直接引用全局对象（推荐）
self;     // 简写：等价于 window，指向当前窗口
```

## 获取方式详解

| 获取方式 | 作用与说明                                                   |
| -------- | ------------------------------------------------------------ |
| `window` | 浏览器环境下的全局对象，所有全局变量、函数和对象本质上都是 `window` 对象的属性或方法。 |
| `self`   | 始终指向当前窗口，与 `window` 完全等价。                     |

## 常用属性

| 属性               | 作用与说明                                                   |
| ------------------ | ------------------------------------------------------------ |
| `document`         | **只读**。返回对当前窗口所包含的 DOM 文档的引用，是操作页面内容的入口。 |
| `location`         | 获取/设置。包含当前页面的 URL 信息，提供了页面跳转、重定向等功能。 |
| `history`          | **只读**。返回对 History 对象的引用，允许访问和操控浏览器的历史记录。 |
| `navigator`        | **只读**。包含有关浏览器和运行环境的大量信息（如 `userAgent`、`cookieEnabled`）。 |
| `screen`           | **只读**。返回用户的屏幕信息，如屏幕的宽度和高度等。         |
| `innerWidth`       | **只读**。返回浏览器窗口的内容区域（视口）的宽度，包含滚动条，不含工具栏和边框。 |
| `innerHeight`      | **只读**。返回浏览器窗口的内容区域（视口）的高度，包含滚动条，不含工具栏和边框。 |
| `outerWidth`       | **只读**。返回整个浏览器窗口的宽度，包含地址栏、标签栏、窗口边框等。 |
| `outerHeight`      | **只读**。返回整个浏览器窗口的高度，包含地址栏、标签栏、窗口边框等。 |
| `top`              | **只读**。始终指向最外层的浏览器窗口（即最顶层的框架）。     |
| `parent`           | **只读**。指向当前窗口的直接上层窗口。如果当前窗口本身就是顶层，则等于 `self`。 |
| `frames`           | **只读**。返回当前窗口中所有子框架（`<frame>` 或 `<iframe>`）形成的类数组对象。 |
| `devicePixelRatio` | **只读**。返回当前显示器中物理像素和设备独立像素（CSS 像素）之间的比率。 |

## 常用方法

| 方法                                 | 作用与说明                                                   |
| ------------------------------------ | ------------------------------------------------------------ |
| `alert(message)`                     | 显示一个带有指定消息和“确定”按钮的警告框。会阻塞主线程。     |
| `confirm(message)`                   | 显示一个带有指定消息、“确定”和“取消”按钮的对话框。返回布尔值。 |
| `prompt(message, default)`           | 显示一个提示用户输入的对话框。返回用户输入的字符串或 `null`。 |
| `open(url, name, features, replace)` | 打开一个新的浏览器窗口或标签页，并返回对该窗口的引用。       |
| `close()`                            | 关闭当前浏览器窗口。出于安全考虑，通常只能关闭由脚本自身调用 `open()` 创建的窗口。 |
| `setTimeout(callback, delay)`        | 在指定的毫秒数后调用一次函数或执行表达式。                   |
| `setInterval(callback, interval)`    | 按照指定的周期（毫秒）重复调用函数或执行表达式。             |
| `clearTimeout(timeoutID)`            | 取消由 `setTimeout()` 设置的定时任务。                       |
| `clearInterval(intervalID)`          | 取消由 `setInterval()` 设置的定时任务。                      |
| `requestAnimationFrame(callback)`    | 在下一次浏览器重绘之前调用指定的回调函数，常用于制作高性能动画。 |
| `scrollTo(x, y)`                     | 把内容滚动到指定的坐标位置。                                 |
| `scrollBy(x, y)`                     | 按照指定的像素值来滚动内容（相对当前位置）。                 |
| `print()`                            | 触发浏览器的打印对话框，用于打印当前窗口的内容。             |
| `postMessage(message, targetOrigin)` | 安全地实现跨源通信，允许不同源的窗口之间传递数据。           |

# 时间间隔

`setInterval`（注意是 Interval，不是 TimeInterval）。

## 使用格式

```javascript
setInterval(
  function, // 必填：要重复执行的函数或代码片段
  delay,    // 必填：每次执行之间的时间间隔，单位为毫秒（1秒 = 1000毫秒）
  arg1,     // 可选：传递给执行函数的第一个参数
  arg2,     // 可选：传递给执行函数的第二个参数
  ...       // 可选：可以传递任意数量的额外参数
);
```

## 参数详解

| 参数              | 作用                                                   | 可选值及说明                                                 |
| ----------------- | ------------------------------------------------------ | ------------------------------------------------------------ |
| `function`        | 指定需要被周期性重复执行的函数或代码块。               | 具名函数（如 `myFunc`）、<br />匿名函数（如 `function() {}`）或<br />箭头函数（如 `() => {}`）。<br />不推荐传入字符串，因为存在与 `eval()` 相同的安全风险。 |
| `delay`           | 指定每次执行之间的延迟时间。                           | 数值类型，单位为毫秒。<br />如果未指定，默认值为 `0`（即尽快执行，但并非立即执行）。<br />大多数浏览器中，最小延迟时间被限制为 `4` 毫秒，即使设置小于 `4` 毫秒，浏览器也会自动调整为 `4` 毫秒。 |
| `arg1, arg2, ...` | 当定时器触发时，作为参数传递给 `function` 的额外数据。 | 任意类型的值（如字符串、数字、对象等）。<br />这些参数会在每次定时器执行时，按顺序传入到目标函数中。 |

## 代码示例

```javascript
// 定义一个需要重复执行的函数，并接收两个参数
function printMessage(message, count) {
    console.log(`第 ${count} 次打印：${message}`);
}

// 启动定时器，每 1000 毫秒（1秒）执行一次，并传递参数
const intervalID = setInterval(printMessage, 1000, "Hello, World!", 1);

// 补充说明：setInterval 会返回一个唯一的 intervalID
// 当不需要定时器继续执行时，可以使用 clearInterval(intervalID) 来停止它，以防止内存泄漏
```

# 非数字判断

在 JavaScript 中，`isNaN()` 是一个全局函数，用于判断一个值是否为 `NaN`（Not-a-Number，非数字）。

## 使用格式

```javascript
isNaN(value); // value: 必需。要检测是否为 NaN 的值
```

## 参数详解

| 参数    | 作用与说明                                                   |
| ------- | ------------------------------------------------------------ |
| `value` | 指定需要被检测的值。该函数会**首先尝试将参数转换为数字**，然后再判断转换后的结果是否为 `NaN`。 |

- 数字类型

  合法数字返回 `false`，`NaN` 返回 `true`。

- 字符串类型

  可转为数字的（如 `"123"`、`""`）返回 `false`；无法转换的（如 `"hello"`）返回 `true`。

- 布尔值

  `true` 转为 `1`，`false` 转为 `0`，均返回 `false`。

- null

  转换为 `0`，返回 `false`。

- undefined

  转换为 `NaN`，返回 `true`。

- 对象/数组

  转换失败，返回 `true`。

## 代码示例

```javascript
// 1. 检测真正的 NaN 和算术错误
console.log(isNaN(NaN));        // true
console.log(isNaN(0 / 0));      // true

// 2. 检测合法的数字
console.log(isNaN(123));        // false
console.log(isNaN(-1.23));      // false

// 3. 隐式类型转换带来的“陷阱”
// 空字符串会被转换为 0，所以不是 NaN
console.log(isNaN(""));         // false 

// 纯数字字符串可以被成功转换
console.log(isNaN("123"));      // false 

// 无法转换为数字的字符串，返回 true
console.log(isNaN("hello"));    // true 

// undefined 转换为 NaN，返回 true
console.log(isNaN(undefined));  // true 
```

## 现代开发避坑提示

由于全局的 `isNaN()` 存在隐式类型转换，行为常常令人困惑。在现代 JavaScript（ES6+）开发中，还可使用 `Number.isNaN()`。它不会进行类型转换，只有当传入的值**本身就是 `NaN`** 时才会返回 `true`。
