# form-serialize

## 介绍

`form-serialize` 是一个轻量级的 JavaScript 工具库，专门用于将 HTML 表单（`<form>` 元素）中的数据序列化为特定的格式。

## 核心作用

1. 简化数据收集

   自动遍历表单内的所有有效控件（如 `<input>`、`<textarea>`、`<select>` 等），快速收集用户输入的值，避免手动逐个获取 DOM 元素值的繁琐操作。

2. 格式化输出

   支持将收集到的表单数据转换为 URL 编码的查询字符串（默认格式）或 JavaScript 对象（JSON 格式），便于通过 AJAX 请求提交给服务器。

3. 灵活配置

   提供多种配置选项，允许开发者自定义序列化行为，例如是否包含空值、是否包含禁用字段等。

## 安装与引入方式

1. NPM 安装

   在终端执行 `npm install form-serialize` 命令进行安装，随后在 JavaScript 文件中通过 `import serialize from 'form-serialize'` 或 `const serialize = require('form-serialize')` 引入。

2. CDN 或本地引入

   在 HTML 文件中通过 `<script>` 标签引入 `form-serialize.min.js` 文件，引入后全局会挂载 `serialize` 方法。

## 使用方法

`form-serialize` 的核心是调用 `serialize()` 函数。该函数接收两个参数：

| 参数位置    | 参数类型        | 作用说明                                         |
| ----------- | --------------- | ------------------------------------------------ |
| 第 1 个参数 | HTMLFormElement | 必填。需要被序列化的表单 DOM 元素对象。          |
| 第 2 个参数 | Object          | 可选。配置对象，用于控制序列化的输出格式和行为。 |

> **第二个参数常用属性**
>
> | 配置项       | 类型       | 默认值       | 作用说明                                                     |
> | ------------ | ---------- | ------------ | ------------------------------------------------------------ |
> | `hash`       | `boolean`  | `false`      | 设置为 `true` 时，返回 JavaScript 对象；<br />设置为 `false` 时，返回 URL 编码字符串，也就是查询参数格式。 |
> | `empty`      | `boolean`  | `false`      | 设置为 `true` 时，即使表单字段值为空也会被包含在结果中；<br />设置为 `false` 时，空值字段会被忽略。 |
> | `disabled`   | `boolean`  | `false`      | 设置为 `true` 时，被禁用的表单字段也会被序列化；<br />默认情况下禁用字段会被忽略。 |
> | `serializer` | `function` | 内置序列化器 | 允许传入自定义函数，以覆盖默认的 URL 编码或 Hash 序列化逻辑。 |
>
> 一般会把 `hash` 和 `empty` 设置为 `true`。

## 代码示例

```javascript
// 1. 获取表单 DOM 元素
const form = document.querySelector('#my-form');

// 2. 序列化为 URL 编码字符串（默认行为）
// 结果示例："username=john&password=123456"
const queryString = serialize(form); 

// 3. 序列化为 JavaScript 对象，并包含空值
// 结果示例：{ username: "john", password: "123456", bio: "" }
const formData = serialize(form, { hash: true, empty: true }); 

// 4. 结合 AJAX (Fetch API) 提交表单数据
fetch('/api/submit', {
    method: 'POST',
    headers: {
        'Content-Type': 'application/json'
    },
    body: JSON.stringify(serialize(form, { hash: true }))
});
```

## 注意事项

- `name` 属性要求

  表单内的控件必须设置 `name` 属性，`form-serialize` 依赖 `name` 属性的值作为序列化后数据的键名。未设置 `name` 属性的控件会被自动忽略。

- 文件上传限制

  `form-serialize` 仅处理常规表单字段，不包含 `<input type="file">` 的文件数据。若需上传文件，应使用原生的 `FormData` 对象。

- 复选框与多选框

  当使用 `{ hash: true }` 模式时，同名复选框或多选下拉框的值会自动聚合为数组形式。若字段名以 `[]` 结尾（如 `hobbies[]`），即使只有一个选中项，也会被强制序列化为数组。
