# 字符串

`String` 是 JavaScript 中用于处理文本数据的内置对象。它既可以作为构造函数（配合 `new` 关键字）创建字符串包装对象，也可以作为普通函数将任意类型的值转换为字符串。在现代开发中，绝大多数场景下直接使用字符串字面量（单引号或双引号）即可，`String` 对象主要用于类型转换或访问其丰富的静态方法（如 `String.fromCharCode()`）。

## 实例化格式

```javascript
// 1. 作为普通函数使用（类型转换，推荐）
const str1 = String(value);
// value：需要被转换为字符串的值。如果是对象，会优先调用其 toString() 方法。

// 2. 作为构造函数使用（创建字符串包装对象，不推荐）
const str2 = new String(value);
// value：用于初始化字符串包装对象的原始值。
```

## 参数详解

| 参数名称 | 作用描述                 | 可选值或数据类型                                             |
| -------- | ------------------------ | ------------------------------------------------------------ |
| `value`  | 指定要转换或初始化的值。 | 任意数据类型（字符串、数字、布尔值、对象、null、undefined 等）。 |

## 常用静态方法

| 方法名称                                 | 作用描述                                                     |
| ---------------------------------------- | ------------------------------------------------------------ |
| `String.fromCharCode(num1, num2, ...)`   | 根据指定的 Unicode 编码值，返回一个由对应字符组成的字符串。  |
| `String.fromCodePoint(num1, num2, ...)`  | 根据指定的 Unicode 码点，返回一个字符串（支持超出基本多文种平面的字符）。 |
| `String.raw(template, ...substitutions)` | 作为模板字符串的标签函数，返回原始字符串（不处理转义字符，如 `\n` 会原样输出）。 |

## 常用实例属性与方法

| 属性/方法名称                           | 作用描述                                                     |
| --------------------------------------- | ------------------------------------------------------------ |
| `length`                                | 返回字符串的长度（即 UTF-16 代码单元的数量）。               |
| `charAt(index)`                         | 返回指定索引处的字符。                                       |
| `charCodeAt(index)`                     | 返回指定索引处字符的 Unicode 编码（0 到 65535 之间的整数）。 |
| `indexOf(searchValue, fromIndex?)`      | 返回指定值在字符串中首次出现的索引，若未找到则返回 -1。      |
| `includes(searchString, position?)`     | 判断字符串是否包含指定的子字符串，返回布尔值。               |
| `slice(beginIndex, endIndex?)`          | 提取字符串的一部分（从 beginIndex 到 endIndex，不包含 endIndex），<br />返回新字符串。 |
| `substring(indexStart, indexEnd?)`      | 返回字符串中介于两个指定下标之间的字符。<br />与 slice 类似，但不支持负数索引。 |
| `split(separator, limit?)`              | 使用指定的分隔符将字符串分割成数组。                         |
| `replace(searchValue, replaceValue)`    | 返回一个由替换值替换部分匹配后的新字符串。<br />支持正则表达式和函数作为替换逻辑。 |
| `replaceAll(searchValue, replaceValue)` | 返回一个由替换值替换所有匹配项后的新字符串。                 |
| `toUpperCase()`                         | 将字符串转换为大写形式。                                     |
| `toLowerCase()`                         | 将字符串转换为小写形式。                                     |
| `trim()`                                | 清除字符串两端的空白字符。                                   |
| `trimStart()` / `trimEnd()`             | 分别清除字符串开头或结尾的空白字符。                         |
| `startsWith(searchString, position?)`   | 判断字符串是否以指定的子字符串开头。                         |
| `endsWith(searchString, length?)`       | 判断字符串是否以指定的子字符串结尾。                         |
| `repeat(count)`                         | 返回一个由指定次数重复拼接而成的新字符串。                   |
| `padStart(targetLength, padString?)`    | 在当前字符串开头填充指定字符串，直到达到目标长度。           |
| `padEnd(targetLength, padString?)`      | 在当前字符串末尾填充指定字符串，直到达到目标长度。           |
| `match(regexp)`                         | 检索返回一个字符串匹配正则表达式的结果数组。                 |
| `search(regexp)`                        | 执行正则表达式和字符串之间的搜索匹配，返回首次匹配的索引。   |

# 数字

`Number` 是 JavaScript 中用于表示数字值的内置对象。它既可以作为构造函数（配合 `new` 关键字）创建数字包装对象，也可以作为普通函数将任意类型的值转换为数字原始值。

在现代开发中，绝大多数场景下直接使用数字字面量即可，`Number` 对象主要用于类型转换、访问其丰富的静态常量（如最大安全整数）以及调用其静态方法（如 `Number.isNaN()`）。

## 实例化格式

```javascript
// 1. 作为普通函数使用（类型转换，推荐）
const num1 = Number(value);
// value：需要被转换为数字的值。如果是对象，会优先调用其 valueOf() 方法。

// 2. 作为构造函数使用（创建数字包装对象，不推荐）
const num2 = new Number(value);
// value：用于初始化数字包装对象的原始值。
```

## 参数详解

| 参数名称 | 作用描述                 | 可选值或数据类型                                           |
| -------- | ------------------------ | ---------------------------------------------------------- |
| `value`  | 指定要转换或初始化的值。 | 任意数据类型（字符串、布尔值、对象、null、undefined 等）。 |

## 静态属性

| 属性名称                   | 作用描述                                                     |
| -------------------------- | ------------------------------------------------------------ |
| `Number.MAX_VALUE`         | 表示 JavaScript 中能表示的最大正数。                         |
| `Number.MIN_VALUE`         | 表示 JavaScript 中能表示的最小正数（最接近 0 的正数）。      |
| `Number.MAX_SAFE_INTEGER`  | 表示 JavaScript 中最大的安全整数（2^53 - 1）。               |
| `Number.MIN_SAFE_INTEGER`  | 表示 JavaScript 中最小的安全整数（-(2^53 - 1)）。            |
| `Number.POSITIVE_INFINITY` | 表示正无穷大。                                               |
| `Number.NEGATIVE_INFINITY` | 表示负无穷大。                                               |
| `Number.NaN`               | 表示“非数字”（Not-A-Number）的特殊值。                       |
| `Number.EPSILON`           | 表示 1 与大于 1 的最小可表示数之间的差值，常用于浮点数比较。 |

## 静态方法

| 方法名称                          | 作用描述                                                     |
| --------------------------------- | ------------------------------------------------------------ |
| `Number.isNaN(value)`             | 判断传递的值是否为 `NaN`，且不会进行类型转换（严格判断）。   |
| `Number.isFinite(value)`          | 判断传递的值是否为有限数值（不是 `NaN`、`Infinity` 或 `-Infinity`）。 |
| `Number.isInteger(value)`         | 判断传递的值是否为整数。                                     |
| `Number.isSafeInteger(value)`     | 判断传递的值是否为安全整数（在 `MIN_SAFE_INTEGER` 到 `MAX_SAFE_INTEGER` 之间）。 |
| `Number.parseInt(string, radix?)` | 解析字符串并返回一个整数。功能与全局 `parseInt()` 相同。     |
| `Number.parseFloat(string)`       | 解析字符串并返回一个浮点数。功能与全局 `parseFloat()` 相同。 |

## 实例属性

| 属性名称      | 作用描述                                 |
| ------------- | ---------------------------------------- |
| `constructor` | 返回创建该数字对象的 `Number` 函数引用。 |

## 实例方法

| 方法名称                             | 作用描述                                                     |
| ------------------------------------ | ------------------------------------------------------------ |
| `toString(radix?)`                   | 将数字转换为字符串。可指定基数（radix），如 2（二进制）、10（十进制）、16（十六进制）。 |
| `toFixed(digits?)`                   | 将数字格式化为**指定小数位数的字符串**（四舍五入）。         |
| `toExponential(fractionDigits?)`     | 将数字转换为指数计数法表示的字符串。                         |
| `toPrecision(precision?)`            | 将数字格式化为指定有效数字长度的字符串。                     |
| `toLocaleString(locales?, options?)` | 返回数字在特定语言环境下的格式化字符串（如添加千分位分隔符）。 |
| `valueOf()`                          | 返回数字对象的原始数字值。                                   |
